# Backroom Protocol

Backroom Protocol is a first-person survival maze game inspired by the Backrooms universe, developed in Unity.

## Features
- 3 maze levels with increasing difficulty
- Enemy spawning and survival-based gameplay
- Health and ammo pickups
- Automatic level progression with countdown timers
- Atmospheric fog, darkness, glowing enemy eyes, and level-specific music
- Health, ammo, timer, and level UI

## Controls
- **W / A / S / D** or **Arrow Keys** — Move
- **Left Mouse Button** — Shoot

## Goal
Survive all three levels and defeat the enemies. Complete the game to see **"You're free"** — or get consumed.
